## 1. Frontière `DocumentSource` / ingestion

Le pipeline gelé sait déjà ingérer **un répertoire local** : `ingerer(dossier=…)`
accepte n'importe quel dossier, et toute la logique de déduplication, de
détection « inchangé » et de suppression est portée par `RegistreFichiers`,
à partir du **contenu du répertoire**.

La frontière retenue n'est donc pas *dans* `ingerer()` : c'est **« produire le
répertoire — un snapshot complet — que `ingerer()` sait déjà ingérer »**.

```
origine (dossier local aujourd'hui ; API / GED / autre demain)
        │
        ▼
DocumentSource.materialiser()  ──▶  répertoire = SNAPSHOT COMPLET  (Path)
        │
        ▼
IngestionService.sync(source)  ──▶  ingerer(dossier=…)      [socle gelé, inchangé]
        │
        ▼
découverte → hash → doc_id → parsing → chunks → embeddings → Qdrant
```

Le pipeline reçoit un **`Path` de répertoire**, pas des `bytes` ni un `stream` :

- tous les loaders de `src/rag/loaders.py` (gelé) sont écrits pour un chemin
  (`pdfplumber.open`, `python-docx`, `openpyxl`, `pandas.read_csv`,
  `pdf2image.convert_from_path`) ; l'OCR exige un vrai fichier ;
- `charger_document` dispatche sur `chemin.suffix` ;
- `ingerer(dossier: Path)` existe déjà — zéro refactor ;
- `RegistreFichiers` est keyé par chemin : un miroir local **stable** (chemins
  reproductibles d'un run à l'autre) garde la détection « inchangé » /
  « supprimé » fonctionnelle **sans toucher au socle**.

## 2. Invariant de sûreté — `materialiser()`

Le socle interprète *« présent au registre, absent du répertoire »* comme une
**suppression documentaire** (`RegistreFichiers.entrees_absentes` →
`supprimer_document`). Exposer un répertoire **incomplet** au pipeline
effacerait donc de l'index des documents qui n'ont pas disparu — ils ont
seulement échoué à être récupérés.

> **Invariant.** Le `Path` exposé par `materialiser()` représente TOUJOURS un
> snapshot complet et cohérent de la source à un instant donné — jamais un
> état partiel, jamais un état en cours de construction.

Corollaires, contraignants pour toute implémentation :

- une récupération incomplète lève `ErreurSource` **sans rien exposer** :
  `materialiser()` ne `yield` pas → `IngestionService.sync` n'appelle jamais
  le pipeline → l'index reste tel quel ;
- une nouvelle matérialisation se construit **à l'écart** ; elle ne remplace
  le snapshot précédent qu'**après succès complet**, de façon atomique pour un
  lecteur ;
- une absence de document ne peut être lue comme une **vraie** suppression
  **que parce que** le snapshot est garanti complet.

`LocalDocumentSource` satisfait l'invariant trivialement : il n'y a aucune
étape de récupération faillible, le dossier de l'utilisateur *est* le
snapshot.

## 3. Contrat

`src/sources/base.py`

```python
class DocumentSource(Protocol):
    def materialiser(self) -> AbstractContextManager[Path]: ...   # snapshot complet
```

`ErreurSource` : échec d'accès à la source **entière** (répertoire introuvable,
récupération distante incomplète, snapshot invalide…), levé **avant** toute
écriture Qdrant. Distinct de `src.rag.loaders.ErreurChargement`, qui porte sur
un document individuel *pendant* l'ingestion.

Il n'y a **pas** de modèle `DocumentDescriptor` : le contrat ne fait rien
circuler document par document (le socle re-découvre depuis le répertoire), et
aucun helper réel n'en avait l'usage. Un connecteur qui aurait besoin d'un
descripteur riche le définira pour ses besoins propres.

## 4. `LocalDocumentSource` — adaptateur MVP

`src/sources/local.py`

- `materialiser()` renvoie le dossier de l'utilisateur **tel quel** : aucune
  copie, aucun répertoire temporaire, aucun nettoyage. Donc
  `IngestionService().sync(LocalDocumentSource(d))` est **strictement
  équivalent** à `ingerer(dossier=d)`.
- `inventaire() -> list[str]` : identifiants stables (chemins relatifs POSIX,
  triés) des documents que le pipeline ingérerait. **Hors contrat** —
  commodité (observabilité, tests). Réutilise `decouvrir_fichiers` du socle,
  jamais une seconde implémentation de la découverte.
- Lève `ErreurSource` si le chemin est absent ou n'est pas un répertoire.

## 5. `SnapshotDocumentSource` — base pour source à récupération faillible

`src/sources/snapshot.py` — rend l'invariant **difficile à violer**. Une
sous-classe n'implémente que `_recuperer(staging)` ; `materialiser()` est
fourni :

1. crée un répertoire de *staging* neuf, voisin du miroir publié ;
2. appelle `_recuperer(staging)` — qui remplit intégralement, ou lève ;
3. **échec** (`_recuperer` lève, ou staging vide sans `autoriser_snapshot_vide`)
   → staging détruit, miroir publié **strictement intact**, `ErreurSource`
   relevée, aucun `yield` ;
4. **succès complet** → le staging **remplace atomiquement** le miroir publié
   (renommages de répertoires ; un `<miroir>.precedent` résiduel est résorbé
   au run suivant) ;
5. `yield` le miroir publié — snapshot complet.

Le miroir publié est **persistant** (non supprimé en sortie) : nécessaire pour
que la détection de changement du socle, qui compare des chemins d'un run à
l'autre, reste stable.

`autoriser_snapshot_vide` (défaut `False`) : un `_recuperer` qui laisse le
staging vide est traité comme un échec silencieux. Ne passer `True` que si
« la source ne contient réellement aucun document » est un état légitime —
publier alors un snapshot vide supprime tout le corpus, volontairement.

## 6. Futurs connecteurs entreprise

Un connecteur entreprise (non fourni) héritera de `SnapshotDocumentSource` :

- `_recuperer(staging)` récupère **tous** les documents via l'API / GED, avec
  des noms de fichiers reproductibles (dérivés de l'identifiant GED), et
  **lève à la moindre récupération incomplète** ;
- la publication atomique et l'invariant de snapshot sont hérités, non
  réécrits ;
- une absence dans un snapshot complet = vraie suppression → le socle retire
  le document de l'index.

**Aucune hypothèse** n'est faite sur ces APIs : pas d'URL, pas d'auth, pas de
dépendance SharePoint / S3 / etc. `EnterpriseDocumentSource` **n'est pas** créé
à ce stade.

## 7. Sémantique — qui gère quoi

| Aspect | Où c'est géré |
|---|---|
| identité stable d'un document | nom de fichier dans le snapshot → `identifiant_version_document` + clé `RegistreFichiers` (socle) |
| nom / source d'origine | nom de fichier dans le snapshot → `chemin.name` / payload `source` (socle) |
| métadonnées | inférence LLM du socle (`analyser_document`) — **pas** la source |
| contenu / hash / « inchangé » | `empreinte_fichier` + `RegistreFichiers.est_inchange` (socle) |
| document inchangé | hash + signature pipeline identiques → court-circuit (socle) |
| **erreur de récupération** | `ErreurSource` avant le `yield` — snapshot jamais exposé, pipeline jamais appelé, index intact |
| **document supprimé** | absent d'un **snapshot complet** → `RegistreFichiers.entrees_absentes` → `supprimer_document` (socle) |
| snapshot partiel | impossible : staging détruit, miroir précédent conservé, `ErreurSource` |
| format non supporté | filtre d'extension de `decouvrir_fichiers` ; sinon `ErreurChargement` → échec compté, run non interrompu (socle) |
