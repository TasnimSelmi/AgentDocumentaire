# P2.3 — API HTTP FastAPI du MVP

> Couche de **transport** (`src/api/`) au-dessus des façades applicatives déjà
> stabilisées. Elle ne contient **aucune** intelligence documentaire.
> `src/rag/**`, le cœur P1, `src/agent/service.py` et `src/sources/**` ne sont
> **pas modifiés** (`git diff rag-v1 -- src/rag` vide).

---

## 1. Rôle et frontière

```
Client / Streamlit futur
        │  HTTP / JSON
        ▼
     FastAPI  (src/api/**)   ── transport + validation Pydantic + mapping HTTP
      /                 \
     ▼                   ▼
AgentService         IngestionService
(src/agent/service)  (src/sources/service)
     │                   │
executer_agent      DocumentSource  (registre backend : "local" → data/documents)
(cœur P1 gelé)           │
     │              ingerer(dossier=…)   (socle RAG gelé)
     └──────── RAG V1 ───────┘
```

Une route fait conceptuellement, et rien d'autre :

```
validation HTTP  →  un appel de service  →  adaptation de la réponse HTTP
```

Aucune logique de routage, de capacité (SEARCH / SUMMARIZE / CLASSIFY /
EXTRACT / COMPARE / SYNTHESIZE), d'ingestion, de résolution documentaire, de
Qdrant, ni de re-normalisation d'`AgentResponse` n'est présente dans
`src/api/**`.

## 2. Points d'entrée consommés (inchangés)

| Route | Service | Symbole exact |
|---|---|---|
| `POST /query` | `AgentService.query(requete: str) -> AgentResponse` | `src/agent/service.py` (P2.1) |
| `POST /ingestion` | `IngestionService.sync(source, *, reinitialiser, limite, inferer, nom_profil) -> RapportIngestion` | `src/sources/service.py` (P2.2) |

## 3. Endpoints

### `GET /health`

Liveness pur. **Ne sonde ni Ollama, ni Qdrant, ni la source documentaire**
(ce serait un *readiness check*, hors périmètre MVP).

```
200  { "status": "ok" }
```

### `POST /query`

```jsonc
// requête
{ "query": "Compare les rapports A et B" }
```

La réponse est **`AgentResponse.vers_dict()` tel quel** — le contrat public
unique défini en P1.3 (`src/agent/response.py`, `architecture.md` §7.5). Aucun
modèle Pydantic ne le reproduit.

```jsonc
// réponse (forme ; voir §7.5 de architecture.md pour le détail des champs)
{
  "status": "success" | "refusal" | "error",
  "capability": "search" | "summarize" | "classify" | "extract" | "compare" | "synthesize" | "",
  "answer": "…",
  "sources": [ { "citation", "document", "page", "categorie", "extrait", "hors_perimetre" } ],
  "citations": ["S1", "D1S2", …],
  "warnings": [ … ],
  "data": { … },
  "metadata": { … },
  "error": { "code", "message" } | null
}
```

Mapping HTTP :

| Cas | Détection | Statut | Corps |
|---|---|---|---|
| Corps malformé (`query` absent, mauvais type, clé en trop) | Pydantic (`extra="forbid"`) | **422** | détail Pydantic |
| Requête vide / blanche | `AgentService` → `status="error"`, `error.code="requete_invalide"` | **422** | `AgentResponse` (message API fixe) |
| Succès | `status="success"` | **200** | `vers_dict()` intact |
| **Refus fonctionnel** (preuves insuffisantes, document introuvable, multi-doc non fiable, budget épuisé…) | `status="refusal"` | **200** | `vers_dict()` intact (`status:"refusal"`, `error.code` métier) |
| Échec technique | `status="error"` et `code != "requete_invalide"` | **500** | `vers_dict()` avec `error` **remplacé** par `{"code":"internal_error","message":"Une erreur interne est survenue."}` |
| Exception levée par la façade | propagée à la route | **500** | `{ "detail": "Erreur interne." }` |

> **Un refus fonctionnel n'est pas une panne HTTP.** `AgentService` reste
> l'**autorité unique** sur la validité d'une requête : une requête vide ou
> blanche n'atteint jamais le cœur P1 (elle ressort en `requete_invalide`,
> traduite en `422`).

### `POST /ingestion`

```jsonc
// requête — tous les champs sont optionnels ; toute clé inconnue → 422
{ "source": "local", "reinitialiser": false, "limite": null }
```

- `source` : **nom logique** d'une source autorisée, résolu côté backend
  contre un registre `nom -> fabrique DocumentSource` (§4). **Jamais un chemin
  du système de fichiers.**
- `reinitialiser`, `limite` : transmis tels quels à `IngestionService.sync`.
- `inferer` et `nom_profil` **ne sont pas exposés** par l'API MVP (réglages
  serveur).

Réponse de succès : le `RapportIngestion` du socle, **intact**
(`dataclasses.asdict`), y compris lorsqu'il compte des échecs par fichier
(`fichiers_en_echec > 0` reste un `200` — le socle compte les échecs sans
interrompre le run).

| Cas | Statut | Corps |
|---|---|---|
| Corps malformé / clé interdite (`path`, `dossier`, `racine`, …) | **422** | détail Pydantic |
| `source` inconnue du registre | **422** | `{ "detail": "Source inconnue : …" }` |
| Ingestion réussie (même avec `fichiers_en_echec > 0`) | **200** | `asdict(RapportIngestion)` |
| `ErreurSource` (répertoire configuré absent, snapshot incomplet, récupération distante en échec…) | **503** | `{ "detail": "Source documentaire temporairement indisponible." }` |
| Exception inattendue du pipeline | **500** | `{ "detail": "Erreur interne." }` |

## 4. Sélection de la source — contrainte de sécurité

Le client **ne choisit pas** un chemin serveur. Il désigne au plus une source
par un nom logique. La résolution se fait contre un **registre backend** de
fabriques :

```python
# src/api/dependencies.py
def registre_sources_par_defaut() -> dict[str, Callable[[], DocumentSource]]:
    return {"local": lambda: LocalDocumentSource(get_settings().documents_dir)}
```

- MVP : une seule entrée, `"local"`, adossée au dossier documentaire configuré
  (`Settings.documents_dir`, lu à chaque appel de la fabrique).
- `IngestionRequest` a `model_config = {"extra": "forbid"}` : une clé `path` /
  `dossier` / `racine` / inconnue provoque un `422` **avant** tout appel de
  service — aucune valeur de la requête n'atteint jamais `LocalDocumentSource`
  ni le système de fichiers.
- Ajouter une source (connecteur entreprise implémentant `DocumentSource` via
  `SnapshotDocumentSource`, cf. [P2.2_SOURCES.md](P2.2_SOURCES.md)) = **ajouter
  une entrée au registre**, jamais un paramètre HTTP ni une modification de
  `src/sources/**`. Conforme à [DO_NOT_TOUCH.md](DO_NOT_TOUCH.md) §4 (toute
  source passe par `IngestionService.sync()`).

## 5. Structure `src/api/`

| Fichier | Rôle |
|---|---|
| `app.py` | `create_app(*, agent_service, ingestion_service, sources)` — câble routes + gestionnaires d'erreur, pose les collaborateurs sur `app.state`. |
| `routes.py` | un `APIRouter`, trois routes très courtes. |
| `schemas.py` | `QueryRequest`, `IngestionRequest`, `HealthResponse` (entrées) + `rapport_vers_dict` (helper de sortie). **Aucun** modèle miroir d'`AgentResponse`. |
| `errors.py` | `statut_http_pour(AgentResponse) -> int`, `corps_reponse_query` (masque l'erreur technique), gestionnaires `ErreurSource` → 503 et `Exception` → 500. |
| `dependencies.py` | fabriques **paresseuses** des collaborateurs par défaut + registre de sources. |

Injection : `create_app` accepte des collaborateurs explicites (doublures en
test) ; sinon il les construit paresseusement. Importer `src.api` ou appeler
`create_app()` ne touche ni Ollama, ni Qdrant, ni le système de fichiers.

## 6. Lancement

Aucun module `__main__` n'est fourni (design P2.3). Lancement standard :

```bash
uvicorn "src.api:create_app" --factory --host 127.0.0.1 --port 8000
```

`tests/api/` — **40 tests, tous hors ligne** (`TestClient` +
`AgentService` / `IngestionService` remplacés par des espions ;
`raise_server_exceptions=False`). Couverture :

- `test_health` : `200 {"status":"ok"}` ; aucun collaborateur sollicité.
- `test_query` : délégation exacte (1 appel, argument intact) ; `success` →
  200 ; **refus métier → 200** et corps intact ; échec technique → 500 **sans
  fuite** (ni `ConnectionError`, ni chemin, ni secret) ; requête vide/blanche
  → 422 via `AgentService`, **cœur P1 jamais appelé** ; corps malformé / type
  invalide / clé en trop → 422 ; fidélité de la sérialisation du contrat
  public ; `/query` ne touche pas l'ingestion.
- `test_ingestion` : rapport renvoyé intact ; source par défaut = `"local"` ;
  options transmises ; **tout chemin client (`path`, `dossier`, `racine`) →

  inconnue → 422 ; `ErreurSource` (façade ou fabrique) → 503 **sans fuite** ;
  exception inattendue → 500 sans fuite ; `fichiers_en_echec > 0` reste 200 ;
  `/ingestion` ne touche pas l'agent.
- `test_errors` : `statut_http_pour` et `corps_reponse_query` isolés.
- `test_app` : `create_app()` offline ; OpenAPI expose exactement
  `/health`, `/query`, `/ingestion` ; **aucun schéma `AgentResponse`** dans
  l'OpenAPI ; injection des collaborateurs ; registre par défaut =
  `{"local"}` pointant sur `Settings.documents_dir`.

## 8. Limitations MVP (assumées)

- **Pas d'authentification** (hors périmètre P2.3). `POST /ingestion` mute
  l'index : ne pas exposer cette API publiquement sans couche d'auth en amont.
- **Ingestion synchrone** : la requête `POST /ingestion` reste ouverte le
  temps du pipeline (pas de tâche de fond — exclusion Celery / scheduler).
- **`/health` = liveness seul** : ne garantit pas que Qdrant / Ollama
  répondent.
- Un seul nom de source (`"local"`). Les connecteurs entreprise ne sont pas
  fournis (P2.2 §6).
